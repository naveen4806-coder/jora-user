# Security Policy

## Supported Version

Jora is actively maintained on the `main` branch. Security fixes are released there.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Send vulnerability reports privately to:

rsnaveensiva@gmail.com

Include:

- A clear description of the issue
- Steps to reproduce it
- Affected page or feature
- Screenshots or proof of concept, if safe to share
- Your suggested fix, if available

## Response Time

We aim to:

- Confirm receipt within 3 business days
- Assess the report within 7 business days
- Keep you updated until the issue is resolved

## Scope

Please report issues involving:

- Authentication or account access
- Customer, vendor, or delivery data exposure
- Payment and checkout security
- Firebase, API, or database access controls
- XSS, CSRF, injection, or broken authorization
- Exposed API keys, secrets, or configuration

## Security Rules

- Never post customer information, passwords, API keys, tokens, or secrets publicly.
- Do not access, modify, or delete other users’ data.
- Do not interrupt Jora services or perform denial-of-service testing.
- Test only accounts and data you own or have explicit permission to use.

Thank you for helping keep Jora secure.
