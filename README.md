# Jora Delivery

Jora Delivery is a local shopping and delivery web application. It helps users explore nearby shops, view products, add items to a cart, and continue to checkout.

## Features

- Opening/loading screen
- Shop and product browsing
- Product details
- Shopping cart workflow
- Guest checkout flow
- Responsive design for mobile and desktop

## Built With

- React
- Vite
- JavaScript
- HTML and CSS
- Firebase services

## Run Locally

```bash
npm install
npm run dev
```

Open the local link shown in the terminal.

## Build for Production

```bash
npm run build
```
